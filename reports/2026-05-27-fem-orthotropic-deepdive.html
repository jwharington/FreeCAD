3. New Feature Deep-Dive

3.1 Orthotropic material + local coordinate system pipeline

Outcome: Orthotropic material definitions and orientations now propagate from material object to CalculiX sections and output conventions.
  • material_common.py adds LocalCoordinateSystem (App::PropertyLinkGlobal) on material objects.
  • meshsetsgetter.py now injects orientation into material-geometry sets for solids/shells and handles element-wise orientation where needed.
  • write_femelement_material.py emits *ELASTIC,TYPE=ENGINEERING CONSTANTS when orthotropic constants are present.
  • write_femelement_geometry.py emits *ORIENTATION blocks and attaches orientation to section cards.
  • write_step_output.py changes element result export to *EL FILE, GLOBAL=NO, aligning result tensors with local material axes.

Impact: This is the core feature path enabling physically meaningful anisotropic analysis output rather than only isotropic assumptions.

3.2 Laminated/draped shell support

Outcome: Composite shell workflows gain drape-aware orientation and laminate material collection for writer output.
  • New femmesh/drapetools.py for:
    • composite shell detection,
    • drape LCS extraction by FEM element,
    • laminate resolution and material collection.
  • meshsetsgetter.py supports heterogeneous shell orientation (element_ids + per-element orientation map).
  • membertools.py tracks indirect laminate materials via shell geometry refs.
  • write_femelement_geometry.py writes per-element ELSET sections for heterogeneous orientation and composite section payloads.
  • write_femelement_material.py writes laminate materials from laminate proxies in addition to direct linear materials.

Impact: Enables laminated shell decks beyond constant-thickness isotropic shell assumptions, with drape-specific orientation support.

3.3 Failure models & Stress Exposure Factor (SEF)

Outcome: New failure-criterion computation layer with UI-visible node result channel (StressExposureFactor).
  • New femresult/failuremodels.py defines maximum strain/stress, Tsai-Wu, and Hashin criteria + scalar minimization-based exposure factor.
  • resulttools.py adds add_stress_exposure_factor, applied during FRD import.
  • importCcxFrdResults.py invokes SEF computation for feature-python objects in the result parent group.
  • result_mechanical.py, FemVTKTools.cpp, and task_result_mechanical.py expose SEF in data model + UI.

Impact: Adds a practical failure-oriented result quantity and foundations for future material-allowable-driven post processing.

3.4 Orthogonal (non-FEM orthotropic) changes

  • ad20bad160: global unit-system extension introducing areal mass units.
  • f65d035231: GUI build fix for Gizmo QFlags conversion.

These are orthogonal to FEM orthotropic/composite work and should be separated in history if the branch is intended as a clean FEM-focused PR series.

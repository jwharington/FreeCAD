## 0. What this is

A day's work on the stiffener flow while porting a fuselage to the workbench.
Three defects were taken to their mechanical root; two are fixed and measured,
the third (the seat cut) is now implemented on the correct rule but was
**committed without a test run** at the user's instruction — read §2 first.

### Constraints in force (do not violate)

- **No extrusion. No conversion of anything to a solid.**  Primitive OCCT
  operations only.
- **No centre-of-mass (or other geometric) filtering.**  A piece's origin is
  available exactly; use it.
- Never weaken an assertion or a threshold to make a test pass.
- Hand stiffeners **plain loft** supports (§3, #11).

## 2. Committed without a test run — read this first

`16b15a71ec` — *select remainder pieces by provenance, not by centre of mass*.

**What it does.** `_support_remainders` now splits each support face by the
stiffener's faces and keeps a piece only when the fuse records that it came
from the **support alone**. A piece generated by the support *and* a tool is
the region they share — the seat — and is dropped. That is the whole rule;
no geometry is guessed and the centre-of-mass filter is deleted.

**Why it matters.** The previous selection took *every* piece the fuse
returned, so the **stiffener's own swept faces** were listed as support
remainder — those are the five stray surfaces in
`/home/jmw/Desktop/stiffener-review/07-ring-remainder-fragments.png`. The
filter that was hiding this is exactly what the user ruled out.

**Expected outcome (not yet observed):**

- Ring (`test_ring_frames`): the sleeve *is* the frame section, so the support
  has no surface beyond the seat and the **remainder is empty** — the
  geometry's own answer, which is what `test_seat_cut_is_justified_by_the_geometry`
  asserts (empty, *and* the area identity to justify it). Both ring tests
  should pass; the `5 != 0` failure belonged to the old selection.
- Plate fixtures (`test_stiffener`): the two margins beside the seat should
  come back — `test_support_is_left_with_the_stiffener_cut_away` and

## 3. Open items, in order

### 3.1 The chained seam validation (expected blocker for the provenance rule)

When a second stiffener sits on a panel whose support has been re-pointed to
the first one's remainder, the seam check cannot find the boundary it wants.
Leading candidate: the Master's live shape is empty or otherwise lacks the
contact, because the chain's remainder was fully consumed.

**Next step (one cycle):** in `SeamCompositeLaminate._validate_wiring`, print
the Master shape's face count and each clause's outcome, then run
`run-tests.sh test_stiffener_composite_shell`. If the count is 0, fall back to
the panel's captured pre-insertion support (`SupportBackup`) instead of
raising, and reconcile with the `_resupport_panel` contract (a consumed
remainder is a legitimate state).

### 3.2 The cone offset case (#13)

`test_t_section_on_a_tilted_cut_of_a_conical_panel` expects 80 and gets 60:
there OCCT's offset gives up too, and the rebuilt row differs. The rebuild
must reproduce the offset's geometry for a conical generator (its `b` is not
the `t x N` of a planar row).

### 3.3 Part-side scaffolding

`FuselageV2.py`'s `_frame_sleeve` still pre-trims its sleeves with a boolean
`common`. Scaffolding only — the airframe geometry is built separately and is
unaffected — but it must be reduced to a **plain loft** spanning the frame
section, or the seat cut silently disappears on that part (#11). The ported
script has not yet been run end to end.

## 5. Things worth knowing before touching this

- **A surface that has been through a Boolean cannot be split or cut by
  anything** in this OCCT build — measured against `cut`, `generalFuse`,
  `SplitAPI.slice`, 1-D tools, and `fuzzy_value` 1e-3/1e-2. This is all of
  #11: hand over a plain loft.
- **`_shape_of` re-derives the support shape on every call**, so
  `Shape.hashCode()` changes between calls, and content fingerprints walk
  vertices in traversal order (a rebuilt compound fingerprints differently for
  identical geometry). Caches keyed on either miss every time; the
  order-independent `shape_stamp` works.
- **A face cut along a curve on it stays one face** with unchanged area (the
  cut appears as an internal edge) — "one face, same area" is not evidence
  that nothing happened.
- **`Shape.BoundBox` over-reports on these B-spline faces** (it can be the
  whole untrimmed surface's box). Compare areas, not bounding boxes.
- `_resupport_panel` keeps a panel on its own support when a seat leaves no
  remainder; it *hides* the seat-cut defect rather than fixing it, and the
  validation contract around consumed remainders is what §3.1 runs into.

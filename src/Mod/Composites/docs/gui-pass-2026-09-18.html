Capture method

The first pass captured through the interactive GLSL weave shader, which does not survive offscreen capture faithfully. These screenshots use the new Coin-native capture mode (features/CoinWeaveCapture.py): the weave shader is detached and each shell renders through plain Coin3D state — an RGBA weave texture mapped by the surface's UV coordinates, with a texture matrix carrying the layer's fibre angle and grid spacing, mirroring the shader uniforms. Rosettes, cut edges and native geometry are Coin-native already. The interactive shader path is untouched and remains the GUI renderer; capture mode is enter/exit per shell.
